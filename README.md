# Online FoodShop

This is a basic Online FoodShop website made using HTML and CSS.

I made this project while learning the basics of web development and CSS. It includes a home page, navigation bar, featured products section and a Contact Us page.

## Technologies Used

- HTML
- CSS

## Features

- Navigation bar
- Featured products section
- Order buttons
- Contact Us form
- Responsive design using CSS media queries

## Files

- `index.html` - Main webpage
- `contact.html` - Contact Us page
- `style.css` - Styling for the website

## How to Run

Download or clone the repository and open `index.html` in your browser.
